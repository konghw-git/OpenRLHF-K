# Official Docs Map (crawled mirrors in learning-docs)

`docs/learning-docs/` is a **separate git repository** (`konghw-git/learning-docs` on GitHub), gitignored by this repo — if the directory is missing locally, clone it there first. It mirrors official docs of projects relevant to this work (EN original + ZH translation generated by its `tools/` Gemini pipeline; see its README for adding new sites).

**Use these as the authoritative reference** when answering questions about features, options, or setup — prefer citing a page over reasoning from memory. Pages are static HTML; readable text sits in the main content div. Sphinx sites also keep plain-text sources under `_sources/*.rst.txt` — often easier to read than HTML.

## vLLM — `docs/learning-docs/vllm.io/`

English under `en/`, Chinese under `zh/` (same tree). Crawled from docs.vllm.ai/en/latest — a large MkDocs site; navigate by directory: `getting_started/`, `serving/`, `models/`, `features/` (quantization, LoRA, structured output…), `configuration/`, `design/` (architecture internals), `api/` (auto-generated API reference). Start from `index.html` or the section's own index page rather than guessing filenames.

## Conventions

- Do not hand-edit `zh` translations — they are generated; fix systematic issues by rerunning the pipeline (`uv run --project tools tools/polish_docs.py <site>` inside learning-docs).
- When upstream docs update: re-crawl the site's `en` tree (wget command in learning-docs README), then rerun the translation pipeline.
